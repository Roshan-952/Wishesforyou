# Wishesforyou ✨🎂

A magical and interactive birthday surprise web experience with custom animations, ambient music, friendship letters, memory cards, and a surprise gift box reveal.

## Features
- 🎀 Interactive welcome gateway with animations
- ✨ Floating ambient sparkles & petals
- 💌 Special friendship letters & envelopes
- 📸 Photo memory reveal cards
- 🎁 Birthday gift box surprise
- 🎵 Audio player & soft chime sound effects

## Tech Stack
- HTML5
- CSS3 (Custom animations & styling)
- JavaScript (Vanilla)
